# Histórico de versões

O arquivo para download de cada versão está em [Releases](https://github.com/glpisalvador/glpisas/releases).

## 1.0.0 — 2026-10-03

Primeira versão. Substitui o antigo plugin "Controle Administrativo".

- **Limites por período** para perfis, entidades e grupos, com aviso e bloqueio.
- **Horas contratadas** com valores, por entidade, grupo ou usuário.
- Painel, registro de criações, auditoria e exportação CSV.
- Migração dos dados do plugin antigo, quando existirem.
